# Caveat — рукописная надпись курса

Выбран 22 октября 2026 года как окончательный шрифт надписи «Авторский курс Николая Чернобаева». Пользователь разрешил выбрать свободный кириллический рукописный шрифт; воспроизведение личного почерка не требуется.

- Семейство: **Caveat**, дизайнер Impallari Type.
- Copyright 2014 The Caveat Project Authors (https://github.com/googlefonts/caveat).
- Лицензия: **SIL Open Font License 1.1**. Полный неизменённый текст и copyright находятся в [OFL.txt](OFL.txt).
- Коммерческое использование и локальное подключение через CSS `@font-face` разрешены. Условия распространяются на шрифт; сайт не обязан распространяться под OFL.
- При копировании или публикации шрифта сохранять `OFL.txt` рядом с файлом. Не продавать шрифт отдельно и не менять его лицензию. В данном OFL нет отдельного объявления Reserved Font Names.

## Файлы

- `hero-note-cyrillic.woff2` — подмножество Google Fonts для этой конкретной фразы, 11 532 байта; подключено локально, начертание 400, CSS-псевдоним `HeroHandwriting`.
- `Caveat-wght.ttf` — исходный полный вариативный шрифт; сохранён для происхождения и возможного расширения текста, в браузере не загружается.
- `verification.json` — SHA256, нужные буквы и проверка заявленного диапазона символов.

Подмножество предназначено именно для указанной надписи. При изменении текста повторно проверить набор букв или подключить подходящее полное подмножество. Оригинальные файлы не переименовывались внутри шрифта и не редактировались.
